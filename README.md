# UMA GROUP

Статический сайт выставочных и событийных пространств. Главная страница — `index.html`, полное портфолио — `works.html`.

Локальный просмотр: `python3 -m http.server 4173`.

Форма заявки работает только как интерфейс: данные и выбранные файлы не отправляются. Для рабочей отправки нужен серверный обработчик и утверждённая политика обработки данных.

Шрифт [Onest](https://github.com/google/fonts/tree/main/ofl/onest) хранится локально в `assets/fonts/` и распространяется по лицензии SIL Open Font License 1.1 (`assets/fonts/OFL.txt`).
