FRAMEX — два направления

Локальные концепты для согласования. Одинаковое содержание, разная композиция, типографика, масштаб фото и цвет. Публичный сайт не изменён.

A+ · «Светлый зал»

Светлый первый экран с крупным заголовком и знаком, который при прокрутке становится рамой. Фиолетовый из логотипа — для действий, коралловый — для выделений и блока «Рассчитать стенд», сиреневый — фон вопросов. Лента бренда, строки услуг, форма с размером стенда и файлом.

Что важно знать при просмотре

  • Подпись «фреймикс» — пример места и стиля. Написание, шрифт и расположение не утверждены.
  • У концептов разная анимация текста. A: слова заголовков выезжают снизу, слоган печатается по буквам. B: по словам проходит цветная плашка, слоган проявляется из размытия.
  • Заставки тоже разные. A: буквы выезжают, X становится рамой и обратно, печатается «фреймикс», заставка уезжает вверх. B: буквы открывают коралловые плашки, X влетает с поворотом, становится рамой и обратно, затем из X раскрывается синее окно и переходит в первый экран.
  • Заставка показывается один раз за сеанс. В A кнопки «Пропустить» больше нет — по просьбе клиентки; клавиша Esc для клавиатуры остаётся. При системной настройке «уменьшить движение» заставки нет.
  • Тексты — редакторская версия черновиков из брифа и блока «О нас». Исправлено: «во впечатления»; лишняя «э» перед «превращая» убрана.
  • В концепте B одна карточка — пример того, как подписывать ИИ-визуализации. Это не проект FRAMEX.
  • Формы демонстрационные: ничего не отправляют.
